DUSTLINE — a round-based tactical FPS in the browser: 5v5 EMBER vs SABLE with bots, bomb plant and defuse, a round economy with a buy menu, five weapons and a grenade. Built with three.js 0.187.0, no build step, no network.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — click to lock the pointer and play.
